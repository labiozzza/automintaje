# Экран + голова

Набор **edit-***. База — **edit-talking-cut** (для части с лицом). Для интерфейсов, нарисованных кодом, — **video-graphics**; этот скилл — про **настоящую** запись экрана. Выдуманный экран за продукт не рисовать.

## Раскладки
| Раскладка | Экран | Спикер | Когда |
|---|---|---|---|
| Кружок | весь кадр, кроп по вертикали к области действия | круг Ø 260–300 px в нижнем углу, белая обводка | основная |
| Сплит | верх 55 % | низ 45 % (как Беляк) | спикер много жестикулирует |
| Только экран | весь кадр | нет, голос | длинный показ шагов |
| Только лицо | — | весь кадр | вывод, мнение |

## Приёмы
1. **Автозум к курсору.** Координаты курсора: из записи OBS со слоем курсора или по разнице кадров (где меняется маленькая область); вручную — ключевые точки `zoom.json` (t, x, y, масштаб). Зум 1,6–2,4×, переход 0,5 с `easeInOutCubic`, держится, пока действие в этой зоне.
2. **Клик.** Кольцо 60→120 px, гаснет за 0,25 с + тихий клик −26 дБ.
3. **Подсветка.** Остальной экран притемнён 50 %, область — скруглённый прямоугольник с жёлтой рамкой 6 px.
4. **Ускорение.** Загрузка, ожидание ответа нейросети, долгий ввод → ×4–×8 с бейджем «×4» и тиканьем часов; голос в это время продолжает объяснять.
5. **Размытие личного.** Почта, токены, имена, вкладки, уведомления — гаусс 18 px или плашка; проверять каждый кадр, где это видно.
6. **Набор текста.** Если в записи печатают долго — заменить на ускорение или на вставку итогового текста с эффектом печати (только тем же текстом, что в записи).

## Шаги
1. Запись экрана в исходном разрешении (Retina 2×), 30/60 fps. Курсор крупный (системная настройка), уведомления выключены.
2. `edit-talking-cut` 1–5 для лица; запись экрана синхронить по звуку или по хлопку/клику.
3. `screen.json`: кусок → раскладка → зумы → подсветки → ускорения → размытия.
4. Кадры экрана → `seq/screen/`, зум в HTML из исходных кадров полного разрешения (не из уже ужатых).
5. Рендер; лист — по кадру на каждый зум и каждое размытие.

## Раскадровка-шаблон
1. Общий экран продукта, спикер кружком.
2. Автозум к области, курсор и клик, подсветка.
3. Экран результата (зум на ответ), бейдж ×4 на ожидании перед ним.

## Проверка
- Текст на экране после зума читается на телефоне (≥ 26 px).
- Ни одного кадра с личными данными.
- Курсор не «телепортируется» на склейках ускорения — сглаживать или прятать.

## Грабли
- Зум «прыгает» от каждого движения мыши — зумить только по кликам и паузам курсора > 0,4 с.
- Тёмная тема интерфейса + тёмный фон ролика сливаются — рамка окна 2 px светлая.
