# Видеостудия: оркестратор

Ролик собирается **кодом**: сцены — HTML/canvas-страница с функцией `renderAt(t)`, браузер рендерит её покадрово, ffmpeg склеивает с голосом и музыкой. Так получаются точная синхронизация с голосом, чистая типографика и любые интерфейсы без After Effects.

| Скилл | За что отвечает |
|---|---|
| **video-studio** (этот) | тип ролика, конвейер, точки согласования, выдача |
| **video-voice** | текст для озвучки, тайм-коды слов, темп и паузы, музыка, сведение |
| **video-images** | генерация картинок (фоны, предметы, вырезки), правка с сохранением композиции |
| **video-graphics** | цифры, графики, карты, разрезы, интерфейсы, переходы — кодом |
| **video-styles** | выбор стиля, палитры и шрифты, разбор референса |
| **video-montage** | шаблон сцен, привязка к словам, безопасные зоны, листы кадров, рендер |

**Нужно на компьютере:** Node.js 18+, Python 3 + numpy, ffmpeg, `npm i playwright && npx playwright install chromium`, ключ `OPENAI_API_KEY` (тайм-коды whisper и картинки).

## 1. Тип ролика

| Тип | Формат | Длина | Особенности |
|---|---|---|---|
| Объяснялка / научпоп | 9:16 | 45–75 с | хук до 2-й секунды, событие каждые 1–2 с, ключевые слова на экране |
| Реклама продукта | 9:16 | 20–45 с | интерфейс продукта кодом, вырезки людей/предметов, звук на каждое появление |
| Гайд по интерфейсу | 16:9 | 45–120 с | экраны по скриншотам/макетам, курсор, подсветки, «ШАГ N ИЗ M» |
| Видеопрезентация | 16:9 | 2–4 мин | слайд → сцена, крупные цифры, схемы |
| Говорящая голова + графика | 9:16 | 30–90 с | видео спикера + субтитры и вставки поверх |
| Сторис | 9:16 | 5–8 с | одна мысль, место под стикер-ссылку |

Не ясно — спросить одним сообщением: формат, длина, есть ли голос (запись / нейроголос / без голоса), для кого ролик, стиль или референс.

## 2. Конвейер

Шаги с ★ — показать результат и дождаться «да».

1. **Бриф:** цель, зритель, одна главная мысль, формат, длина. ★
2. **Текст закадра** (≈ 2 слова в секунду):
   - хук — первые 1–2 фразы: вопрос или переворот, который бьёт в зрителя («ты делаешь это неправильно»), контекст ролика — уже в первом кадре;
   - середина — короткие фразы, по одной мысли, открытые петли («но самое странное — дальше»);
   - финал — без пересказа «итак», последний факт → обращение к зрителю или вопрос для комментариев;
   - факты — только проверенные, источники записать себе. ★
3. **Раскадровка** — таблица «фраза → что на экране → приём». Для 9:16: 10–18 сцен по 2–5 с. Выбрать стиль (**video-styles**). ★
4. **Озвучка** — по чистовику (**video-voice**, §1). Монтаж не начинать без аудио.
5. **Тайм-коды и темп** — **video-voice**, §2–3 → `vo_fast.wav`, `timeline.js`.
6. **Ассеты** — **video-images** (назвать цену, если генерация платная). ★ при большой пачке.
7. **Сцены** — **video-montage** (шаблон) + **video-graphics** (блоки).
8. **Проверка кадров** — кадр на каждую сцену → листы → посмотреть глазами: текст в безопасной зоне, ничего не перекрыто, нет пустых кадров.
9. **Рендер** → **сведение** (**video-voice**, §5) → `out/final.mp4`.
10. **Выдача:** основной mp4; лёгкая копия для мессенджеров (`-crf 26`); обложка (кадр-заголовок, `node render.js scene.html stills 0`); подпись к посту — короткий абзац с новыми фактами, которых нет в ролике, + вопрос.

## 3. Правки

- Точечно — перерендерить кусок `node render.js scene.html video FROM TO seg.mp4` и вклеить (**video-montage**, §6).
- Прошлую версию не затирать: `out/v1/`.
- Новая озвучка поверх готовых сцен: сцены привязаны к словам через `W('слово')`, поэтому после `retime.py` по новому голосу большая часть сцен сдвигается сама; проверить листы.

## 4. Что работает (выводы из ~40 роликов)

- **Кадр 0 не пустой**: текст-контекст и картинка с первого кадра; голос с 0,3 с. Немое интро теряет треть зрителей за 1,5 с.
- **Темп важнее времени на чтение**: голос ×1,25–1,4, хук ×1,5; паузы ≤ 0,3 с.
- **Новое событие каждые 1–2 с**, новый «мир» (фон/палитра) каждые 10–15 с.
- **Ключевое слово фразы на экране** крупно, а не сплошные субтитры (субтитры — отдельной версией).
- **Звук на каждое появление** и свуш на каждую склейку — даёт динамику сильнее, чем анимация.
- **Петля**: последний кадр совпадает с первым — ролик пересматривают.
- **Не слишком темно**: нагнетать темпом, звуком, красным акцентом, а не чёрным экраном.
- Тексты, цифры, интерфейсы — всегда кодом; генерация — только фоны и предметы.
- Не выдумывать цифры; ИИ-картинку не выдавать за реальное фото; лица реальных людей не генерировать.
