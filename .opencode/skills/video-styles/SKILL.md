# Стили

Часть видеостудии (см. **video-studio**). Стиль = переменные `:root` в шаблоне (**video-montage**) + шрифты + правила движения и звука.

## 1. Как выбрать

1. Есть бренд заказчика → его цвета, шрифт и логотип, наша динамика.
2. Объяснялка про тело, быт, науку → «Карточки и миры» + пиксельные герои или научный рентген.
3. Ролик из своих видео → клип-эссе или сюр-коллаж.
4. Инструкция → корпоративный гайд или светлый «госсервис».
5. Есть референс → разобрать (§3), записать дизайн-код, только потом собирать.
6. Серия → у каждой части своя палитра, общие — герои и приёмы.
7. **Не слишком темно:** нагнетать темпом, звуком и красным, а не чернотой; вместо чёрного — глубокий синий `#142238`, фото — в сумерках, не ночью.

## 2. Каталог

### Тёмный неон (tech, «как Remotion/Opus»)
- Фон `#07080B` + точечная сетка + цветное свечение по сцене; 1–2 акцента на сцену: lime `#C8FF3E`, cyan `#46E0FF`, violet `#A58BFF`, pink `#FF4FB0`, gold `#FFC53D`, hot `#FF4A2B`.
- Inter Tight 800–900 italic капсом (заголовки, числа), JetBrains Mono (подписи, данные), Playfair Display italic (одно «возвышенное» слово), Press Start 2P (игры).
- Буквы с blur и пружиной, счётчики, интерфейсы кодом; 1–2 светлые сцены как контраст. Музыка 120–140 BPM по секциям, звук на каждое появление.

### Научный рентген-разрез
- Тёмно-синий фон, циановые/лаймовые контуры, рентген-разрезы домов, тел, приборов; предмет-герой проходит насквозь. Фирменные приёмы: стоп-кадр с подписью → разрез → бесконечный зум → огромная цифра → блэкаут.
- Хорошо для «куда уходит / как устроено внутри».

### Карточки и миры
- Светлый продуктовый 3D + интерфейсные карточки. У каждого раздела свой фон-«мир»: тёмный `#111111` с сеткой, белый, зелёный градиент `#0B7B3F → #A7E68F`, небо `#0074D7 → #02A9FB` с травой, красный `#900102 → #C80B0B`. Мир = смысл: зелёный — просто/хорошо, красный — опасно, тёмный — «внутри», белый — объяснение.
- Google Sans (есть кириллица): строчные заголовки 80/600, в заголовке одна 3D-иконка 0,92 em; цифры 212/400 в плитках; серая подпись-вывод 27 px под композицией.
- Переход между мирами — перетекание цвета с размытием 0,3 с. Звук: голос + SFX или лёгкий бит.

### Пиксельные герои
- Персонаж 18×18 «пикселей» на canvas (тело-круг, глаза, руки/ноги позами), палитры по 4 цвета; собирается и рассыпается из пикселей. Смешно и узнаваемо, держит серию.
- Фото-стикеры предметов с белой обводкой, заголовки 700 с белой обводкой. Звук — чиптюн (треугольный бас, pulse-аккорды) + 8-бит SFX.

### Клип-эссе (красное слово)
- Чёрный фон, свои кадры леттербоксом или во весь рост; огромное красное сжатое слово `#D51B0F` из расфокуса, местами **за человеком** (маска вырезки); мелкие белые капсы лесенкой ~27 px; ещё не сказанное — серым `#8A8A8A`.
- Fira Sans Extra Condensed 900 (сжатый с кириллицей), подписи Inter/Manrope 800. Событие каждые ~0,9 с, эмбиент + свуши на склейках.
- Для тревела: планы 2–4 с, паузы под музыку между фразами, место — крупным титром; без REC и тайм-кодов.

### Сюр-коллаж (жёлтая стопка)
- Архивные фото с «порчей», живопись, морфы; жёлтая стопка слов `#FFC741` слева снизу (x≈105, y 1340–1720), кегль скачет по смыслу (38 / 54 / 100 px), коралловый фон `#D35448`, тёмный `#1A171A`. Montserrat / Inter 800.

### Светлый «госсервис»
- Фон `#EEF2F8`, белые карточки, синий `#0D4CD3`, красный `#E5243B`; Inter. Фейковое приложение, пуши, документы, штампы. Для тем про налоги, документы, деньги.

### Apple-минимализм
- `#F5F5F7` + редкие тёмные сцены для акцента; Inter 700; иконки как в iOS (градиентные скруглённые квадраты с белыми глифами), сегментный переключатель, кольца, большие градиентные цифры, предметы на прозрачном с мягкой тенью.

### Аварийная памятка
- Пиктограммы ISO кодом (человечек с суставами, силуэты), запрещающие знаки, штампы ✓/✗, полосы hazard; заливки жёлтый / оранжевый / красный / зелёный; ночь — силуэт с циановой обводкой. Для «что делать, если…».

### Нуар
- Ч/б + один цветной акцент на кадр, жалюзи, дым, дождь, зерно; один полностью цветной кадр как кульминация. Генерировать в цвете с жёстким светом, ч/б делать кодом (`filter: grayscale(1) contrast(1.3)`, гамма вверх — иначе тени уйдут в черноту).

### Немой разрез «плохо / хорошо»
- Один неподвижный кадр — помещение в разрезе с трубами/устройством; человечек позами делает бытовое действие. Сначала неправильно → провал → красный ✗, жёсткая склейка на тот же кадр, правильно → зелёная ✓. Без голоса и музыки, только бытовые звуки — понятно на любом языке.

### Корпоративный гайд (16:9)
- Цвета и логотип клиента, плашка роли («Ученик», «Сотрудник»), панель «ШАГ N ИЗ M», интерфейс кодом по скриншотам, курсор, рамки-подсветки, камера наезжает на нажатие; тихая музыка 120 BPM.

### Необрутализм
- Паника (тёмный, красный, тряска, RGB-сдвиг) → решение (бумага в клетку, стикеры, толстые обводки, жёсткие тени без размытия); мемные звуки.

## 3. Разбор референса

1. Кадры каждые 0,5 с: `ffmpeg -i ref.mp4 -vf fps=2 -q:v 3 ref/%04d.jpg` → листы (**video-montage**, `sheet.sh ref`) → посмотреть.
2. Замерить: палитру (пипеткой по кадрам), шрифты (подобрать аналог **с кириллицей** на Google Fonts), кегли в px на 1080, раскладку (где заголовок, где контент, поля), частоту событий (смен за 10 с), переходы, звук (музыка, SFX, голос), драматургию по времени.
3. Записать дизайн-код в `styles/<имя>.md`: структура ролика по секундам, палитра токенами, типографика таблицей, раскладка, компоненты, движение, звук, что переносим к себе.
4. Собрать 2–3 тестовых кадра и сравнить бок о бок с кадрами референса; совпало — собирать ролик.
5. Копировать **приёмы и ритм**, а не чужие ассеты, логотипы и персонажей.
