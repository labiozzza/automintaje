# Графика кодом

Часть видеостудии (см. **video-studio**). Каркас (`renderAt(t)`, `W('слово')`, `spr`, `P`, `eo`, `fmt`, `charsIn`, canvas `X`) — в шаблоне **video-montage** (`templates/scene.html`); там уже есть рабочие примеры: заголовок по буквам, счётчик, столбчатый график, телефон с уведомлением, рамка-подсветка и тап.

## 1. Данные → форма

| Что сказать | Форма |
|---|---|
| одна шокирующая цифра | огромная цифра на весь кадр + счётчик или одометр |
| итог / сумма | слот-машина цифр, штамп |
| сравнение A и B | две колонки / «×N» / два столбца рядом с масштабом |
| доля | кольцо, полоска, 100 точек с закрашенными |
| динамика во времени | линия, которая рисуется; столбцы по очереди |
| хронология | таймлайн с метками, HUD «год» |
| география | карта точками/контуром, наезд камеры в точку |
| как устроено внутри | разрез, рентген, изометрия в разборе |
| путь / процесс | один предмет проходит насквозь через разрез |
| шаги инструкции | интерфейс кодом + курсор + рамка + «ШАГ N ИЗ M» |
| план / статус | колонки со статусами и галочками |

**Честность:** только проверенные цифры, источник — мелкой подписью (32–36 px) или в описании; нет данных — не рисовать «примерный» график.

## 2. Фрагменты (вставлять в `renderAt`, `t` — время, `a` — момент слова)

**Счётчик** (DOM): `el.textContent = fmt(VALUE * eio(P(t, a, 0.9)))` — счёт за 0,9 с; единицы (₽, %, л) — отдельным span меньше кеглем.

**Одометр** (каждая цифра — колонка 0–9, едет вверх; значение передавать строкой `fmt(12000)` — тогда сохранится пробел разрядов):
```js
function odometer(el, value, t, a, dur = 1.4){
  const s = String(value), k = eio(P(t, a, dur));
  el.innerHTML = [...s].map((d, i) => { if (!/\d/.test(d)) return `<span>${d}</span>`;
    const y = -(+d + 10 * (s.length - i - 1)) * k % 10;       // старшие разряды крутятся меньше
    return `<span style="display:inline-block;height:1em;line-height:1;overflow:hidden;vertical-align:top"><span style="display:block;transform:translateY(${y}em)">${'01234567890'.split('').join('<br>')}</span></span>`; }).join('');   // лишний 0 в конце — переход 9 → 0 без скачка
}
```

**Кольцо доли** (canvas):
```js
function ring(cx, cy, r, share, t, a, col = '#C8FF3E'){
  const k = share * eo(P(t, a, 0.8));
  X.lineWidth = 46; X.lineCap = 'round';
  X.strokeStyle = 'rgba(255,255,255,.12)'; X.beginPath(); X.arc(cx, cy, r, 0, Math.PI * 2); X.stroke();
  X.strokeStyle = col; X.beginPath(); X.arc(cx, cy, r, -Math.PI / 2, -Math.PI / 2 + Math.PI * 2 * k); X.stroke();
  X.fillStyle = '#fff'; X.font = '900 italic 150px "Inter Tight"'; X.textAlign = 'center'; X.textBaseline = 'middle';
  X.fillText(Math.round(k * 100) + '%', cx, cy);
}
```

**Линия графика, которая рисуется:**
```js
function line(pts, x0, y0, w, h, t, a, dur = 1.2){   // pts — значения 0..1
  const k = eo(P(t, a, dur)) * (pts.length - 1), n = Math.floor(k);
  X.strokeStyle = '#46E0FF'; X.lineWidth = 10; X.lineJoin = 'round'; X.beginPath();
  for (let i = 0; i <= n && i < pts.length; i++) X.lineTo(x0 + w * i / (pts.length - 1), y0 + h * (1 - pts[i]));
  if (n < pts.length - 1) { const f = k - n, xa = x0 + w * n / (pts.length - 1), xb = x0 + w * (n + 1) / (pts.length - 1);
    X.lineTo(xa + (xb - xa) * f, y0 + h * (1 - (pts[n] + (pts[n + 1] - pts[n]) * f))); }
  X.stroke();   // точку-«голову» линии рисовать кружком на конце — глаз следит за ней
}
```

**100 точек** (доля «каждый пятый»): сетка 10×10, точка `i` закрашивается, если `i < share*100`, появление по очереди `spr(t, a + i*0.008)`.

**Курсор с кликом:** позиция — `lerp` между точками по `eio(P(t, a, 0.5))`; клик — кружок `scale(0.4 + p)` с затуханием `1 − p`, плюс кнопка «вдавливается» `scale(0.96)` на 0,1 с. Свой звук click на тот же момент.

**Рамка-подсветка, которая рисуется штрихом** (SVG): `stroke-dasharray = L; stroke-dashoffset = L * (1 − eo(P(t, a, 0.5)))`, где L — периметр.

**Выноска:** точка на объекте → линия (рисуется так же штрихом) → плашка с подписью; плашку держать в безопасной рамке, линия может идти куда угодно.

## 3. Интерфейсы

Всегда кодом (HTML/CSS проще canvas): телефон 500×960 с радиусом 72 и экранами-слоями; окно браузера 16:9 с адресной строкой; Telegram-чат (пузыри, кнопки, «печатает…»); пуш-уведомление съезжает сверху пружиной. **Камера** — `transform: scale() translate()` обёртки интерфейса, наезд на каждое нажатие, с ограничением, чтобы не открывались края. Тёмная тема — копия интерфейса с классом `.dark`, открывается кругом (`clip-path: circle(r at x y)`).

## 4. Карты

- Контур/точки суши: Natural Earth (`land-110m.json` из пакета `world-atlas`) + проекция из `d3-geo` (`geoNaturalEarth1`, для России — `geoConicConformal` с параллелями 52° и 64°). Файлы скачать рядом со сценой (рендер не должен зависеть от сети).
- Точками выглядит современнее контура: сетка 8–12 px, точка — если внутри суши.
- Политические границы — только если нужны по смыслу (спорные территории — источник проблем).
- Наезд в город: масштаб камеры по экспоненте `scale = exp(lerp(ln s0, ln s1, k))` — иначе движение кажется рывком в конце.
- Карту вписывать в 860 px ширины (9:16).

## 5. Разрезы и схемы

- Разрез здания/предмета: силуэт + внутренние слои разными цветами + **один предмет**, который проходит насквозь (капля, пакет, сигнал). Путь предмета — массив точек, позиция от `t`.
- Рентген: тёмный фон, циановые контуры, полоса сканирования открывает «внутренности» (`clip-path: inset()` от `t`).
- Изометрия «в разборе»: слои разъезжаются по вертикали, у каждого — подпись-выноска.

## 6. Переходы и прерывания

- Склейки: `cut` (по умолчанию на сильной доле/слове), `up` (сцена выезжает снизу), `zoom` (из 1.25 в 1), шторка, перетекание цвета с размытием 0,3 с между «мирами».
- **Импакт-кадр:** 1–2 кадра инверсии + чёрный кадр на ударном слове.
- **Стоп-кадр:** сцена замирает (t фиксируется), сверху стрелка и подпись, звук приглушается фильтром.
- **Блэкаут** ≤ 0,3 с — со звуком.
- **Бесконечный зум:** в финале камера уезжает в деталь, из которой начинался ролик → петля.
- Тряска (`SHAKE`) и вспышка (`FLASH`) — не чаще 1–2 раз за ролик.

## 7. Проверка

Всё важное в рамке x 90–990, y 270–1500 (9:16); правая колонка x > 900 на y 1100–1650 и зона субтитров y 1300–1460 свободны от графики. Цифра держится на экране ≥ 1 с после того, как досчиталась. Листы кадров — **video-montage**, §5.
