# Apple Clean

Стиль из набора «20 стилей» (переписан 26.10.2026). База — **edit-talking-cut**. Образец — `motion/belyak_styles20/`, строка 05.

## Палитра и шрифт
- Фон `#F5F5F7`, текст `#1D1D1F`, второстепенный `#86868B`, акцент один (синий `#0071E3`) — только для номеров и иконок.
- Inter 800 для заголовков, трекинг −4 %, 120–560 px. Inter 600 для текста, 46–56 px.

## Правила
1. Одна мысль на сцену. На экране не больше 3 строк текста, кроме карточки функций.
2. Карточка: белая, радиус 36–48, тень 0 30 80 px 4–10 %.
3. Анимация 0,4–0,7 с, `easeOutCubic`: проявление + подъём на 24 px. Никаких тряски, вспышек и резких зумов.
4. Спикер — скруглённая карточка (радиус 40–48) с мягкой тенью, или его нет совсем.
5. Хук «про людей» в этом стиле вялый. Брать стиль с продуктовой части ролика, хук отдавать спикеру.

## Шаги
1. **edit-talking-cut**, шаги 1–5.
2. Сцены: заголовок → карточка функций (3 строки по фразам) → метрика.
3. HTML, рендер, музыка — лёгкая подложка −30 дБ.

## Раскадровка-шаблон
1. «InTruth.» и подзаголовок, спикер в карточке снизу.
2. Карточка из 3 функций, строки загораются по фразам.
3. Огромная «5» и подпись.

## Проверка
- Белые карточки не сливаются с фоном: тень видна на телефоне.
- В кадре одна мысль.
