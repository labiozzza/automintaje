# Hormozi Style

Стиль из набора «20 стилей» (переписан 26.10.2026). База — **edit-talking-cut**, его шаг 6 (punch-in) здесь работает на максимуме. Образец — `motion/belyak_styles20/`, строка 06.

## Ритм и кадр
- Склейка каждые 1–3 с: джамп-каты по тишине + по смене мысли.
- Крупность ступенями: 100 % → 115 % → 130 %, на одном ключевом слове 160–170 % на 0,5–1 с. Внутри куска кадр неподвижен, без тряски и трекинга (правило владельца для штативной съёмки).
- Центр зума — по медиане лица, один на ролик.

## Субтитры
- Montserrat 900, капс. Обычная строка 90 px, ключевое слово 160–200 px, `white-space: nowrap`, автоподбор под ширину 1000 px.
- Обводка 3–5 px чёрная + жёсткая тень 0 8–12 px чёрная.
- Ключевое слово жёлтое `#FFE500` (негатив, «ложь») или зелёное `#3BFF6B` (позитив, «правда»).
- Зона y 1180–1500, по центру. Одна фраза на экране, до 4 слов.

## Правила
1. Хук — с ключевым словом в первые 1,5 с.
2. Вспышка на 2 кадра — только на самом сильном слове ролика.
3. CTA ставить, только если он есть в тексте. Иначе финал — вопрос или панчлайн.

## Шаги
1. **edit-talking-cut**, шаги 1–5.
2. `punch.json`: кусок → крупность, ключевые слова → цвет.
3. HTML, рендер.

## Раскадровка-шаблон
1. Хук «ловит политиков НА ЛЖИ», кадр 115 %.
2. Крупный план 170 % на одно слово CLAUDE.
3. Возврат на общий, «БОЛЬШЕ ПРАВДЫ?» зелёным.

## Проверка
- Субтитр не вылезает за края ни в одном кадре (длинное слово = меньше кегль).
- Нет двух одинаковых крупностей подряд.
