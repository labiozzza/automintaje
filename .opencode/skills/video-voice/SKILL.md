# Голос и звук

Часть видеостудии (см. **video-studio**). Скрипты в папке скилла: `scripts/words.py` (тайм-коды), `scripts/retime.py` (темп, паузы, таймлайн), `scripts/mix.sh` (сведение).

## 1. Текст для озвучки

Отдать два файла:
- **`vo_text.txt`** — ровно то, что произносится: ё везде, ударения в трудных словах (сероводоро́д), английские названия так, как их надо сказать («Джира», «Телеграм»), числа — проверить на слух (падежи), короткие фразы, точка там, где нужна микропауза.
- **Разметка интонаций**:
  - для **ElevenLabs v3** — теги по-английски прямо в тексте: `[confident] [curious] [deadpan] [whispers] [excited] [rushed] [nervous] [sighs] [calm] [serious] [firmly]`;
  - для других сервисов и живого диктора — ремарка по-русски перед фразой: `[быстро, с хитрецой]`, `[ударом, коротко, низко]`, `[голосом новостей, абсолютно серьёзно]`, и общая строка тона в начале: «невозмутимо-научный, смешно за счёт серьёзности; хук быстрее; паузы ≤ 0,3 с; не затухать в конце».
- Для серии роликов — **один и тот же голос** (узнаваемость).

## 2. Тайм-коды слов

```bash
export OPENAI_API_KEY=...
python3 words.py vo.mp3 ru            # → vo_words.json (whisper-1, пословно; ≈ $0,006 за минуту)
```
whisper теряет пунктуацию, путает падежи, режет «кто-то» на два слова, может запаздывать на 0,3–0,8 с. Поэтому субтитры берутся из текста диктора (`--text` в `retime.py`), а спорные места проверяются на слух.

## 3. Темп, паузы, таймлайн

```bash
python3 retime.py vo.mp3 vo_words.json --tempo 1.3 --pause 0.25 --lead 0.3 --text vo_text.txt
# → vo_fast.wav, timeline.json, timeline.js (для шаблона сцен), печатает «сверить вручную» там, где текст и запись разошлись
# горизонталь: --size 1920x1080
```
- Паузы ищутся по громкости (тише `--thr` −40 дБ), длинные укорачиваются до `--pause`; тишина в начале и конце срезается, спереди ставится `--lead`.
- **Ориентиры:** объяснялки ×1,25–1,4 (хук хочется ещё быстрее — до ×1,5, если слова разборчивы); гайды и презентации ×1,05–1,1; говорящая голова ≤ ×1,06 (видно по губам). ×1,45 на всём ролике — слова начинают «западать».
- После — **прослушать** `vo_fast.wav` целиком: не съело ли начало слов, не пропали ли слова.

## 4. Музыка и звуки

- **Музыка:** инструментал без вокала (голос + вокал = каша). Источники — библиотеки с лицензией на коммерческое использование или генерация (Suno и аналоги, режим instrumental; проверить, что нет слов). Темп 110–140 BPM для динамичных роликов; динамика по секциям (тише под важной фразой, дроп после паузы) держит внимание лучше ровной петли.
- **SFX — главный источник динамики:** свой короткий звук на каждое появление (pop, click, whoosh, ding), свуш/удар на каждую склейку, «тейп-стоп» или обрыв музыки перед драматичной фразой, удар после паузы. Пауза/блэкаут ≤ 0,3 с — и со звуком, не полная тишина.
- SFX ставятся по тем же словам, что и сцены: время слова = `timeline.json` → `words[i].t0`. Подмешать к голосу перед сведением:
  ```bash
  ffmpeg -i vo_fast.wav -i whoosh.wav -i pop.wav -filter_complex "[1:a]adelay=3200|3200,volume=0.6[a1];[2:a]adelay=5250|5250,volume=0.5[a2];[0:a][a1][a2]amix=inputs=3:duration=first:normalize=0" vo_sfx.wav
  ```
  (`adelay` в миллисекундах; дальше в `mix.sh` вместо `vo_fast.wav` — `vo_sfx.wav`).

## 5. Сведение

```bash
bash mix.sh out/video.mp4 vo_fast.wav music.mp3 out/final.mp4 0.35 [сдвиг_музыки_с]
bash mix.sh out/video.mp4 vo_fast.wav - out/final.mp4            # без музыки
```
- Музыка зацикливается на длину видео, **приглушается под голосом** (sidechain), затухает в конце; итог — `loudnorm` −14 LUFS (норма соцсетей; на коротких клипах однопроходная нормализация даёт −14…−16, это нормально).
- **Баланс:** голос на 5–6 дБ громче музыки на участках с речью. Проверить в наушниках и на динамике телефона; мешает — уменьшить 5-й аргумент (0,2–0,3).
- Сдвиг музыки (6-й аргумент) — чтобы сильная доля / дроп трека попал на ключевое слово.
- Петля: уровень звука в последние и первые 0,5 с примерно одинаковый, иначе на стыке слышен скачок.

## 6. Звук из видео

Голос из ролика со спикером: `ffmpeg -i src.mov -vn -ac 1 -ar 48000 vo.wav` → дальше как озвучка. Для джамп-катов по паузам `retime.py` подходит только если видео тоже режется по тем же кускам — это уже монтаж видео, не только голоса.
