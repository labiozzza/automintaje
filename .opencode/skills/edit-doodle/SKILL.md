# Рисунок поверх видео

Набор **edit-***. База — **edit-talking-cut** (кадры, маски, `faces.json`). Близкий стиль — «Коллаж на клетке» (`kletka.md`, 12 fps).

## Палитра и линия
- 1–2 цвета на ролик: белый + один акцент (лайм, жёлтый, красный). Чёрный — только на светлом фоне.
- Линия 8–12 px, круглые концы, неровная: SVG-путь с шумом ±3 px.
- Анимация 12 fps («на двойках»): каждый 2–3-й кадр путь перерисовывается с новым шумом — эффект «кипящей» линии. Видео остаётся 30 fps.

## Элементы (библиотека)
| Элемент | Привязка | Когда |
|---|---|---|
| Обводка по контуру | маска человека → контур (marching squares), отступ 14 px наружу | акцент «вот он», ирония |
| Корона / нимб / рожки | над макушкой (верх `faces.json` − 0,3 высоты лица) | «гений», «святой», «злодей» |
| Стрелка «это я» | к лицу/предмету, с подписью | представление, указание |
| Звёзды, «!!!», капли пота | у головы, 3–5 штук | удивление, стресс |
| Зачёркивание | крест поверх слова/скрина | «это неправда» |
| Подпись маркером | шрифт Caveat 700 или рукописный кит | реплика «в сторону» |
| Рамка-клякса | вокруг предмета | показать деталь |

## Правила
1. Не больше одного элемента одновременно, 0,6–1,5 с на экране. Дудл — пунктуация, не фон.
2. Рисуется «от руки»: путь проявляется `stroke-dashoffset` за 0,2–0,35 с, исчезает мгновенно или стирается обратным ходом.
3. Привязка к голове — по `faces.json` того же кадра, но со сглаживанием 5 кадров, иначе корона дрожит отдельно от линии.
4. Лицо и рот не закрывать.
5. SFX: короткий скрип маркера на появление (тихо, −28 дБ).

## Шаги
1. `edit-talking-cut` 1–5.
2. Контуры: из `masks/*.png` в JSON-пути (Python + numpy, marching squares, упрощение Дугласа—Пекера до 60–120 точек) только для кадров с обводкой.
3. `doodle.json`: слово-триггер → элемент → длительность.
4. HTML: слой `<svg>` поверх кадра; функция `wobble(path, seed)` меняет seed раз в 2 кадра.
5. Рендер, лист по одному кадру на элемент.

## Раскадровка-шаблон
1. Обводка по контуру на представлении спикера.
2. Корона/звёзды на панчлайне.
3. Стрелка и подпись маркером к предмету или вставке.

## Проверка
- Линия «кипит», но не дрожит хаотично каждый кадр.
- Обводка не отстаёт от быстрого движения рук (если отстаёт — отключить на куске).

## Грабли
- Контур по сырой маске даёт «волосатую» линию — сначала размытие маски 3 px и порог 50 %.
- Слишком много дудлов превращает ролик в детский — одна штука на 4–6 с.
