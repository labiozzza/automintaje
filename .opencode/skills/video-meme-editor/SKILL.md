# Meme Editor

Стиль из набора «20 стилей» (переписан 26.10.2026). База — **edit-talking-cut**. Образец — `motion/belyak_styles20/`, строка 07.

## Правила юмора
1. Мем только там, где смешно по тексту: противоречие, преувеличение, «звучит как фантастика». Не чаще одного на 8–10 с.
2. Вставка 0,4–1,5 с, жёсткая склейка внутрь и наружу. Звук мема на −6 дБ под голосом, голос не глушить.
3. Подпись-мем: белая плашка, чёрный Inter 800 54 px, сверху кадра, до 8 слов («я, когда политик впервые сказал правду»).
4. После мема — возврат к спикеру с резким зумом 130 % и стикером: плашка под углом −6°, яркий фон (`#FF2D55`), 2–3 слова.
5. Комедийная пауза 0,3–0,6 с перед панчлайном — не вырезать джамп-катом.

## Откуда мемы
- Из ТЗ клиента (у Беляка в ТЗ были «Брюс Всемогущий» и «Я, робот»). Клиент сам отвечает за права на то, что прислал.
- Свои реакции, генерации (**video-images**), лицензированные стоки.
- Сами из интернета не берём.

## Шаги
1. **edit-talking-cut**, шаги 1–5.
2. `memes.json`: слово-триггер → мем (`seq/<имя>/`) → длительность → подпись → стикер после.
3. HTML, звук мемов в `mix.py` отдельной дорожкой.

## Раскадровка-шаблон
1. Тезис спикера на общем плане.
2. Мем на весь кадр 0,8 с с подписью сверху.
3. Возврат: зум 130 % + стикер «СПОЙЛЕР: УЖЕ».

## Проверка
- Каждый мем есть в списке с источником.
- Смысл фразы не потерялся за мемом.
