# Две камеры из одной

Набор **edit-***. База — **edit-talking-cut** (шаги 1–5: синхрон, дубли, джамп-каты, кадры). Этот скилл заменяет её шаг 6 (ступенчатые punch-in) на переключение «камер».

## Когда брать
- Исходник 4K или хотя бы 1080p с запасом по краям (человек занимает треть кадра и меньше).
- Вставок мало или их нельзя брать (права), а держать внимание надо.
- Не брать, если исходник уже крупный план: деталь развалится в пиксели. Порог — в вертикальной «камере» должно остаться ≥ 720 px исходника по высоте.

## Камеры (кропы одного кадра)
| Камера | Что в кадре | Масштаб от вертикали 9:16 по высоте кадра | Когда |
|---|---|---|---|
| A общий | человек, стол, студия | 100 % | начало блока, перечисление, «давайте разберёмся» |
| B средний | грудь и голова | 135 % | объяснение, основной текст |
| C крупный | лицо | 180 % (лимит по качеству) | вопрос, эмоция, панчлайн |
| D деталь | руки, микрофон, ноутбук, предмет | своя точка | жест, «вот этот», считает на пальцах |
| E реальный второй угол | запись экрана OBS, телефон сбоку | — | когда говорит о том, что на экране |

Центр каждой камеры фиксирован на весь ролик (медиана `faces.json` для A–C, вручную для D). Внутри куска кадр не двигается — как настоящая камера на штативе.

## Правила переключения
1. Переключение — только на склейке джамп-ката или на границе фразы, никогда посреди слова.
2. Соседние куски — разные камеры, и разница крупности не меньше одной ступени (A→C можно, B→B нельзя).
3. Камера держится 2–6 с; C не дольше 3 с подряд.
4. Смысловые триггеры по словам whisper: вопросительный знак в `script.txt` → C; числительные и «во-первых» → A или D (руки); имена продуктов, «вот», «смотрите» → E.
5. Раз в 15–20 с — «реверс»: зеркальный кадр не делать (вывески, текст), вместо него D.

## Шаги
1. `edit-talking-cut` шаги 1–5.
2. `cams.json`: прямоугольники камер в координатах исходника + список кусков с камерой. Черновик расставить по триггерам, потом глазами.
3. В HTML: один `<img>` кадра, `object-position` и `transform: scale` из камеры куска; без анимации между ними — жёсткая склейка.
4. Деталь D: если рука уходит из кропа в этом куске — сменить на B.
5. Контактный лист: по одному кадру на кусок с подписью камеры.

## Раскадровка-шаблон
1. A — общий, «Представьте мир…».
2. C — крупный, вопрос или эмоция.
3. D — деталь (руки, микрофон), на жесте или перечислении.

## Проверка
- Шарпность C и D на телефоне: если мыло — уменьшить масштаб или убрать камеру.
- Нет двух одинаковых камер подряд.
- Липсинк после кропов не уехал (кропы не трогают время).

## Грабли
- Шум сенсора на C×180 % в тёмной студии — лёгкий denoise `hqdn3d=1.5:1.5:6:6` только для C.
- Кроп D, в котором случайно видно экран ноутбука с личным — проверить каждый кусок.
