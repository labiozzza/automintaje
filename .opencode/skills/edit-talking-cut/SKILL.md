# Чистый ритм — монтаж говорящей головы

Скилл из набора **edit-*** для работы с реальным видео. Он база: остальные девять (multicam, depth, greenscreen, clones, doodle, freeze, broll, screen-demo, beat) начинают с его шагов 1–5 и добавляют свой приём поверх. Рендер, музыка и упаковка — общие со студией: **motion-video** (HTML `renderAt(t)` + `render.js`), **video-voice** (звук), **video-styles** (стиль, например `belyak.md`).

Эталон — `motion/belyak1/` (рилс Беляка «InTruth», 19–20.10.2026): камера Sony 1920×1080 25 fps + запись OBS с чистым микрофоном и суфлёром.

## Когда брать
- Человек говорит в камеру, есть дубли, оговорки, паузы.
- Нужен темп рилса (40–60 с) без потери смысла.
- Не брать, если голос — закадр без лица (тогда сразу **motion-video**).

## Шаги
1. **Папка и исходники.** `motion/<slug>/src/cam.mp4`, `src/mic.mp4` (если звук писался отдельно) — симлинками на оригиналы, не копиями. Видео из мессенджеров не брать: пережато, маска и зум развалятся.
2. **Синхрон.** `sync.py` из `belyak1`: корреляция огибающих звука камеры и микрофона → сдвиг (у Беляка +2,7025 с). Проверить дрейф на конце файла: если >40 мс, резать на куски и синхронить каждый.
3. **Текст и дубли.** Суфлёр в записи экрана = готовый сценарий (`script.txt`). Whisper по словам (`words.py`) → сверить с `script.txt` (difflib): у каждой фразы берём **последний полный дубль** без оговорок. Дубли вписать в `R` в `edit.py` как пары (начало, конец) времени камеры.
4. **Джамп-каты.** `edit.py`: тишина ниже −42 дБ дольше 0,2 с режется, оставляем 0,1 с воздуха; `TEMPO` 1.03–1.08 (выше — голос «мультяшный»). Границы — только по реальным паузам (правило из **motion-video**, урок `izba`): самое тихое окно 100 мс между словами, иначе съедаются первые звуки. После резки прогнать whisper ещё раз — ни одно слово не должно пропасть. Выход: `vo_fast.wav`, `edl.json` (куски камеры → время ролика).
5. **Кадры и маски.** Кадры камеры по `edl.json` → `frames/NNNNN.jpg` (30 fps, `setpts` под TEMPO). Маски человека и рамки лица: `vision.swift` (Apple Vision, `VNGeneratePersonSegmentationRequest`, accurate) → `masks/*.png`, `faces.json`. **Микрофон Vision в маску не берёт** — дорисовать эллипс поролона и стойку в маску (`ffmpeg geq`, координаты по первому кадру), иначе в груди дыра.
6. **Punch-in ступенями.** Кадр неподвижен внутри куска (штатив, трекинга нет — решение владельца 20.10). Масштаб меняется только на склейке: 100 % → 112 % на смене мысли → 125 % на панчлайне → обратно 100 % на новом блоке. Центр зума — один на весь ролик, по медиане `faces.json`. Два зума подряд одинакового масштаба не ставить: джамп-кат без смены крупности выглядит как сбой.
7. **J/L-каты.** Звук следующей фразы начинается на 0,15–0,3 с раньше картинки (J), когда идёт вставка; L — картинка вставки держится, пока договаривается слово. Склейка по картинке на гласной середине слова, не на паузе.
8. **Субтитры.** По словам из `words.json`, но текст — из `script.txt` (whisper путает падежи). Страница 1–2 строки, до 5 слов, ударное слово цветом стиля. Зона y 1300–1460.
9. **Рендер и звук.** `belyak1.html` как каркас (`setFrame(si)` грузит кадр и маску), `render.js video`, `mix.py`: голос −14 LUFS, бит −35 дБ под голосом.

## Раскадровка-шаблон (3 кадра)
1. Хук: общий план 100 %, первое слово сразу субтитром.
2. Смена мысли: склейка + 112 %, J-кат со вставкой.
3. Панчлайн: 125 %, слово-акцент крупно, после — 0,3 с тишины.

## Проверка
- Контактный лист `sheet.sh` по каждой склейке: нет ли «прыжка головы» без смены крупности.
- Слово в слово с `script.txt`; первые звуки фраз целы.
- Маска на 5 случайных кадрах: края, микрофон, руки у лица.
- Громкость −14 LUFS, пики ниже −1 dBTP.

## Грабли
- Сглаженный трекинг лица «шатает» кадр — запрещён.
- Отдельный микрофон без синхрона даёт липсинк-сдвиг на 2–3 кадра, который видно на «п», «б», «м» — проверять `lipchk.py` из `belyak1`.
- 25 fps камеры → 30 fps ролика: брать ближайший кадр, не интерполировать.
