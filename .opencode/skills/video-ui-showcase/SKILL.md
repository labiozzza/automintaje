# UI Showcase

Стиль из набора «20 стилей» (переписан 26.10.2026). Вся механика (автозум к курсору, клики, ×4, размытие личного) — в **edit-screen-demo**. Этот стиль — его раскладка «экран главный». Образец — `motion/belyak_styles20/`, строка 17.

## Раскладка
- Запись экрана на весь кадр: кроп по вертикали к области действия, фон `#202124`.
- Спикер — круг 280 px с белой обводкой 6 px внизу справа (x 720, y 1480), тень 0 20 50 px.
- Заголовок шага сверху (Inter 800, 56 px), только когда шаг сменился.

## Правила
1. Только настоящие экраны из записи. Если нужного экрана нет — дозаписать, не рисовать.
2. Зум ×2–2,4 к панели или кнопке на слове-триггере, переход 0,5 с. Всё вокруг притемнено на 50 %, рамка-подсветка жёлтая 7 px.
3. Курсор крупный, клик — кольцо и тихий щелчок.
4. Экран результата — финальный кадр с зумом на ответ.
5. Вкладки, почту и токены размыть.

## Шаги
1. Запись экрана + **edit-talking-cut** для спикера.
2. `screen.json` по **edit-screen-demo**.
3. HTML, рендер.

## Раскадровка-шаблон
1. Главный экран: YouTube с панелью InTruth, кружок спикера.
2. Зум ×2 на панель, курсор, подсветка утверждения.
3. Экран результата: вердикт.

## Проверка
- Текст на экране после зума не меньше 26 px.
- Кружок спикера не закрывает кнопку, о которой речь.
