# Data Motion

Стиль из набора «20 стилей» (переписан 26.10.2026). База — **edit-talking-cut**. Готовые блоки графиков, счётчиков и одометров — **video-graphics**. Образец — `motion/belyak_styles20/`, строка 12.

## Вид
- Фон тёмно-синий `#0B1220`, оси `#475569`, линия `#38BDF8` 10 px, точка-акцент `#FACC15`, вердикт оранжевым `#F97316`.
- Inter: заголовок графика 40 px 700, подписи 28–32 px, источник 28 px серым.

## Правила
1. Числа только из источника. У графика — что измеряем, единица, период, источник. Нет точек — нет графика: вместо него сравнение текстом в двух колонках.
2. Линия рисуется 1–1,5 с на фразе про динамику. Отметка ключевой точки — на её слове.
3. Счётчик идёт от 0 до значения за 0,8–1,2 с, с разделителями разрядов.
4. Сравнение «заявление против данных» — две колонки одинаковой высоты, без выдуманных высот столбцов.
5. Спикер — кружок 260 px в углу или его нет.

## Шаги
1. **edit-talking-cut**, шаги 1–5.
2. `data.json`: ряды с источником (таблица, страница, дата). Значения сверить с оригиналом.
3. HTML/SVG-графики, рендер.

## Раскадровка-шаблон
1. Утверждение-цитата карточкой с датой.
2. Линия «реальная почасовая зарплата, % г/г» по таблице BLS A-2.
3. Две колонки «заявление / данные» и вердикт.

## Проверка
- Каждое число на экране находится в источнике.
- Оси и единицы подписаны.
