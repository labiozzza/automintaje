# Картинки для ролика

Часть видеостудии (см. **video-studio**). Скрипт в папке скилла: `scripts/gen_image.py`.

## 1. Генерировать или рисовать кодом

| Генерация | Код (**video-graphics**) |
|---|---|
| фон, локация, фактура | любой текст, надписи, цифры |
| предмет на прозрачном (вырезка) | интерфейсы, кнопки, графики, карты |
| «фото-сюрприз» — один реалистичный кадр на ролик | герой, который повторяется во многих сценах |
| иллюстрация в одном стиле | схемы и разрезы с подписями |

Генеративные модели пишут текст с ошибками и не держат одинаковый вид персонажа от кадра к кадру — **надписи и повторяющиеся герои только кодом**.

## 2. Генерация

```bash
export OPENAI_API_KEY=...
python3 gen_image.py img/kitchen "<промпт>" 1024x1536 low                 # вертикальный фон
python3 gen_image.py img/cup "<промпт>, isolated object" 1024x1024 medium transparent   # вырезка
python3 gen_image.py img/kitchen_night "the same kitchen at night, lights off, keep the composition" 1024x1536 medium --edit img/kitchen.png
```
- Модель — env `IMG_MODEL` (по умолчанию `gpt-image-2`; если у ключа нет доступа — `gpt-image-1.5` или `gpt-image-1`).
- Начинать с `low` (быстро, копейки), `medium`/`high` — для крупных планов и обложки.
- **`--edit`** держит композицию: та же сцена ночью / без света / после ремонта / зимой → переход между ними маской-волной или шторкой. Несколько файлов через запятую: первый — главный, остальные — эталоны персонажа/стиля.
- Прозрачный фон поддерживают не все модели: если альфы нет — генерировать на ровном белом/зелёном фоне и вырезать (`ffmpeg ... colorkey` или маской).

## 3. Промпты

- Всегда добавлять: `no text, no letters, no numbers, no logos, no interface` — иначе модель дорисует фейковый интерфейс, номера, вывески.
- Общий **префикс стиля** на весь ролик (свет, ракурс, плёнка/иллюстрация, палитра) — и короткое описание кадра после него. Так картинки выглядят как из одного ролика.
- Единый стиль надёжнее всего: **одна эталонная картинка** (например, игрушечная диорама города) → все крупные планы через `--edit` от неё.
- Стиль выбирать на 3–6 пробных картинках `low` до основной пачки.
- Люди — со спины, силуэтом, вне фокуса. **Лица реальных людей не генерировать.**
- ИИ-картинку не выдавать за документ, архив или «реальный снимок».
- Если надпись всё же нужна от модели: `text exactly: СКРЫТАЯ ЖИЗНЬ ДОМА (no quotation marks)` — иначе часть моделей рисует кавычки.

## 4. Обработка и вставка

- Обрезать пустые поля по альфе, чтобы позиционировать предмет точно: ffmpeg `cropdetect` или любой редактор.
- **«Рентген» фото** — контуры: `ffmpeg -i img/x.png -vf "gblur=sigma=2.2,edgedetect=low=0.08:high=0.2,colorlevels=rimax=0.35:gimax=0.35:bimax=0.35" img/x_edge.png` (размытие до контуров — иначе каша из мелкой фактуры; `colorlevels` делает линии ярче) → поверх оригинала с `mix-blend-mode: screen`, открывать полосой сканирования.
- Экран телефона/вывеска на фото — рисовать кодом поверх по трём углам (`ctx.setTransform` аффинно), а не генерировать текст.
- Оживлять трансформами: медленный наезд 1.0 → 1.08, параллакс слоёв (фон / предмет / текст двигаются с разной скоростью), лёгкое дрожание; сдвиг фона компенсировать масштабом, чтобы не открылся край.
- Стикер с белой обводкой: CSS `filter: drop-shadow(0 0 0 #fff)` ×4 в разные стороны или обводка силуэта на canvas.

## 5. Оживление кадров (картинка → видео)

Для 1–3 «вау»-моментов: видеомодели (Veo, Kling и аналоги) через их API или агрегаторы.
- Генерировать 5–8 с, брать лучшие 2–4 с и ускорять.
- Режим «первый + последний кадр» — для превращений (предмет → другой предмет) и бесшовной цепочки клипов.
- Видеомодели ломают мелкие предметы и текст — текст поверх кодом.
- Клип в сцену: нарезать кадры `ffmpeg -i clip.mp4 -vf fps=30 shots/clip/%04d.jpg` и показывать нужный кадр от `t` (рендер остаётся детерминированным).

## 6. Пачка

1. Список: id, кадр, промпт, качество, цена → согласовать сумму.
2. Тест 1–3 картинки → показать.
3. Остальное параллельно; каждую картинку посмотреть до вставки в сцену. Брак — одна перегенерация с уточнением, потом — решать кодом.
