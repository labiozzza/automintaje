# Whiteboard

Стиль из набора «20 стилей» (переписан 26.10.2026). База — **edit-talking-cut**. Рукописная линия и «кипение» — как в **edit-doodle**. Образец — `motion/belyak_styles20/`, строка 14.

## Вид
- Доска `#FBFBF8`, чернила `#1A1A1A`, акцент синий `#1D4ED8`, второй акцент терракота `#D97757` (подпись «Claude»), маркер `#FDE047`.
- Caveat 700: заголовки 120–150 px, блоки 70 px, списки 84 px.
- Спикер — кружок 220–260 px с чёрной обводкой 5 px в нижнем правом углу.

## Правила
1. Не больше 5 элементов в одной схеме. Новая схема — стирание губкой (0,4 с) или новый лист.
2. Каждый элемент рисуется `stroke-dashoffset` за 0,3–0,6 с ровно на своей фразе. Текст пишется по буквам.
3. Линии чуть неровные (шум ±2–3 px), стрелки с открытым наконечником.
4. Выделение маркером — полупрозрачная полоса за строкой, проводится слева направо за 0,4 с.

## Шаги
1. **edit-talking-cut**, шаги 1–5.
2. `board.json`: фраза → элемент схемы → координаты.
3. HTML/SVG. Рендер. SFX — тихий скрип маркера −28 дБ.

## Раскадровка-шаблон
1. «Как оно работает?» пишется рукой, подчёркивание.
2. Блок-схема из 4 элементов: эфир → текст → источники → вердикт.
3. Список вердиктов, нужный выделен жёлтым.

## Проверка
- Элемент не появляется раньше своей фразы.
- Текст читается на телефоне (не меньше 70 px).
