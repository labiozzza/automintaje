# Монтаж кодом

Часть видеостудии (см. **video-studio**). В папке скилла: `templates/scene.html` (рабочий шаблон с 4 сценами и субтитрами), `scripts/render.js` (рендер), `scripts/sheet.sh` (листы кадров).

## 1. Папка ролика

```bash
mkdir -p myvideo && cd myvideo
cp <папка этого скилла>/templates/scene.html .
cp <папка этого скилла>/scripts/{render.js,sheet.sh} .
npm i playwright && npx playwright install chromium     # один раз
```
Голос и `timeline.js` — из **video-voice** (`retime.py`). Без `timeline.js` шаблон работает на демо-таймлайне — удобно, чтобы сразу увидеть, как всё устроено: `node render.js scene.html stills 0,2,5,7,9`.

## 2. Как устроен шаблон

- `window.TL = {fps, w, h, end, words:[{w, t0, t1}]}` — таймлайн (1080×1920 или 1920×1080).
- `W('слово', n, запасное)` — время начала n-го вхождения слова в озвучке (регистр, ё и пунктуация не важны). **Всё привязывается к словам**, а не к секундам: поменялся голос — сцены сдвинулись сами.
- `SCN` — таблица сцен `[id, начало, конец, переход]`, переходы `cut | up | zoom | fade`. Каждая сцена — `div.scene` с DOM-элементами; график и фон рисуются на общем `<canvas id="cv">`.
- `renderAt(t)` — **детерминированная**: всё считается от `t`, без `setTimeout`, CSS-анимаций и `Math.random()` (для «случайности» — хеш от индекса). Тогда любой кадр рендерится отдельно, а кусок можно перерендерить.
- Хелперы: `spr` (пружина), `P` (прогресс от момента), `eo/eio` (сглаживание), `split` + `charsIn` (буквы с blur, подъёмом и пружиной; слова не рвутся при переносе), `fmt` (числа с неразрывными пробелами), `captions` (фраза с подсветкой текущего слова).
- `window.ready` — ждёт загрузки шрифтов; картинки добавлять в тот же Promise.
- В браузере без `?render=1` страница проигрывается сама — удобно смотреть сцены.

## 3. Сцены

1. Из раскадровки: 10–18 сцен по 2–5 с, **одна мысль и один визуальный приём на сцену**.
2. Каждое появление — от слова: `charsIn(el, t, W('голос'))`, счётчик стартует на `W('двенадцать')`, свуш в миксе — на том же слове.
3. Ключевое слово фразы — главное слово на экране (крупно). Сплошные субтитры — по желанию (`CAPS = true/false`).
4. Кадр 0 — уже с текстом и картинкой. Новое событие каждые 1–2 с.
5. Готовые блоки инфографики и интерфейсов — **video-graphics**; палитра и шрифты — переменные `:root` (**video-styles**).

## 4. Безопасные зоны (9:16, 1080×1920)

Плеер Reels/TikTok/Shorts срезает бока и накрывает кадр интерфейсом:
- **всё важное — в рамке x 90–990, y 270–1500**; фон и фото — во весь кадр;
- шапка y < 250 — название вкладки и камера; низ y > 1500 — ник, подпись, музыка;
- правая колонка x > 900 на y 1100–1650 — лайк/коммент/репост: там пусто;
- субтитры — y 1300–1460 и x 180–900 (симметрично, но не заходя под кнопки справа);
- ширина строки ≤ 880 px. Жирный курсив капсом ≈ 0,7 em на букву → **максимальный кегль ≈ 1250 / букв в строке**:

| букв в строке | 5 | 6 | 7 | 8 | 10 | 12 | 14 | 16 |
|---|---|---|---|---|---|---|---|---|
| кегль, px | 250 | 210 | 180 | 155 | 125 | 105 | 90 | 78 |

Длинное слово — меньше кегль или короче синоним; фраза — на 2–3 строки по смыслу, главное слово отдельной строкой крупнее. Анимации «удар» и пульс раздувают слово — брать кегль с запасом 5%.

## 5. Проверка кадров — обязательно

```bash
rm -rf stills && node render.js scene.html stills 0,1.5,3.2,5,7.5    # по кадру на сцену + середины переходов
bash sheet.sh                                                       # sheet_0.jpg … по 12 кадров
```
`sheet.sh` закрашивает красным зоны интерфейса соцсетей (для вертикали; `SAFE=0` — без разметки). Открыть листы и проверить: текст в красном, текст перекрыт графикой, пустые кадры, нечитаемость, слова не по голосу. Править → повторить. После рендера — такой же лист из готового mp4 (`ffmpeg -ss T -i out/video.mp4 -frames:v 1 vs/T.jpg` + `bash sheet.sh vs`): пустые секунды видны только там.

## 6. Рендер

```bash
node render.js scene.html video                     # → out/video.mp4 (немой), ≈ 20 кадров/с на простых сценах
node render.js scene.html video 10 14 seg.mp4       # кусок 10–14 с
```
Вклейка куска без полного рендера (F0 = FROM×fps, F1 = TO×fps):
```bash
ffmpeg -v error -y -i out/video.mp4 -i out/seg.mp4 -filter_complex "[0:v]split[v0][v1];[v0]trim=end_frame=F0,setpts=PTS-STARTPTS[a];[1:v]setpts=PTS-STARTPTS[b];[v1]trim=start_frame=F1,setpts=PTS-STARTPTS[c];[a][b][c]concat=n=3:v=1[v]" -map "[v]" -c:v libx264 -crf 17 -pix_fmt yuv420p out/video2.mp4 && mv out/video2.mp4 out/video.mp4
```
Звук — `mix.sh` из **video-voice**.

## 7. Грабли

- Шрифты Google Fonts грузятся из сети: без интернета кадры уйдут в системный шрифт. Выбирать шрифты с кириллицей (Anton и Bebas Neue — без неё).
- Браузер скачивает шрифт, только когда он появился в видимом DOM: шрифты для canvas и скрытых сцен перечислить в `FONTS` шаблона (грузятся явно до рендера), иначе первые кадры сцены — в системном шрифте.
- `render.js` поднимает локальный http — с `file://` маски (`mask-image`) и `fetch` соседних файлов молча не работают.
- Внутри flex-контейнера пробелы между `<span>` схлопываются — оборачивать строку в `<div>`.
- Отрицательный `letter-spacing` слепляет слова — `word-spacing: .14em`.
- Пружина перелетает за 1: подписи-значения брать от `Math.min(p, 1)`.
- Периодическая анимация при отрицательном t: `((x % 1) + 1) % 1`.
- Эмодзи в canvas берут прозрачность из `fillStyle` — перед `fillText` ставить `fillStyle = '#000'`.
- Петля: в последних кадрах проявить сцену начала со временем `t − END`, сравнить последний кадр с кадром 0.
- Зерно и шум раздувают файл — кодировать с `-maxrate 14M -bufsize 28M`.
