# Вставки по смыслу

Набор **edit-***. База — **edit-talking-cut**. Как приходит ТЗ со вставками — см. `belyak1` (ТЗ нумерует вставки по фразам 1–9, 7.1–7.3; видео вставок → `seq/<имя>/` кадры 30 fps).

## Баланс
- Рилс 40–60 с: спикер 40–60 %, вставки 40–60 %. Первые 2 с и последние 3 с — лицо (доверие и финал).
- Вставка 1,2–3,5 с; одна вставка — одно существительное или действие из речи.
- Между двумя вставками — минимум 1,5 с лица, если это не перечисление.

## Приёмы
1. **J-кат.** Звук фразы начинается на лице, картинка вставки приходит на ключевом слове (не раньше).
2. **L-кат.** Вставка держится 0,2–0,4 с после конца слова, лицо возвращается на следующей фразе.
3. **Окно.** Вставка в скруглённом окне на 60–70 % ширины поверх размытого спикера — когда вставка мелкая/вертикальная или важна реакция лица (стиль Беляка — экран сверху).
4. **Весь кадр.** Вставка перекрывает всё — для сильных образов и видео 9:16.
5. **Match cut.** Склейка по совпадению формы/движения: круглый микрофон → круг на вставке, взмах руки → панорама в ту же сторону. Найти 1–2 на ролик, не больше.
6. **Ken Burns.** Фото: наезд 100→108 % или проезд 4–6 % за длину вставки, направление к главному объекту. Никогда не держать фото без движения дольше 1 с.
7. **Подпись.** Источник маленьким кеглем 24–26 px в углу: «Wikimedia Commons, CC BY-SA», «Скрин: factcheck.org», «Генерация ИИ».

## Где брать (по порядку)
1. Материалы клиента/ТЗ.
2. Свои съёмки (`Ролики/Исходники/`).
3. Скрины реальных страниц, записи экрана.
4. Commons и госархивы — с проверкой лицензии (`photos.md` как в `belyak1`).
5. Генерация **video-images** — только для образов («мир, где все говорят правду»), не для фактов; помечать.
Кино и чужие ролики — только если клиент прислал их сам в ТЗ и понимает риск.

## Шаги
1. `edit-talking-cut` 1–5.
2. `broll.md`: таблица фраза → слово-триггер → вставка → режим (окно/весь кадр) → источник/лицензия. Утвердить у владельца до рендера, если вставок нет в ТЗ.
3. Видео вставок → `seq/<имя>/` (ffmpeg `setpts` под длину), фото → Ken Burns в HTML.
4. `M[]` в HTML (как в `belyak1.html`): from/to/keys по словам.
5. Лист: кадр начала каждой вставки + соседнее лицо.

## Раскадровка-шаблон
1. Лицо, J-кат: звук уже о предмете.
2. Вставка окном над размытым спикером.
3. Вставка на весь кадр с Ken Burns и подписью источника.

## Проверка
- Каждая вставка совпадает со словом, а не «где-то рядом».
- У каждой вставки есть строка в `broll.md` с источником.
- Нет двух вставок одного источника подряд, если это не цепочка скринов.

## Грабли
- Вставка «по теме», но не по слову, читается как сток — зритель отваливается.
- Горизонтальное видео на весь вертикальный кадр = кроп 31 %; если главное по краям — только окно.
