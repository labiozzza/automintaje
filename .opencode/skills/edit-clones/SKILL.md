# Двойники

Набор **edit-***. База — **edit-talking-cut** (синхрон, маски). Требует съёмки, спланированной под клонов: без неё приём не собрать.

## Что нужно от съёмки (отдать владельцу заранее)
1. Камера на штативе, не трогать между дублями; ручная экспозиция, баланс белого и фокус — иначе клоны разного цвета.
2. Чистая плита: 3 с пустого кадра без человека в начале.
3. Роли снимаются по очереди в разных зонах кадра (левая/правая треть), не пересекаясь. Роль Б может сменить одну деталь (очки, кепка, худи) — зритель различает клонов за 0,2 с.
4. Реплики с паузами под ответ другого клона; смотреть туда, где будет второй.

## Приёмы
1. **Сплит по шву.** Без масок: левая половина из дубля А, правая из Б, шов — по вертикали, где никто не проходит. Быстро и без артефактов. Шов смягчить градиентом 40 px.
2. **Перекрытие по маске.** Клоны ближе друг к другу или один проходит за другим: дубль Б × маска поверх дубля А. Порядок слоёв — кто ближе к камере.
3. **Появление клона.** На слове-триггере клон Б проявляется: маска растёт снизу вверх 0,3 с + «пуф» (белые частицы) или просто склейка-вспышка 2 кадра.
4. **Реакция-перебивка.** Пока говорит А, Б молча реагирует (закатывает глаза) — это делает скетч живым. Снимать для каждой реплики А реакцию Б.
5. **Субтитры по ролям.** Цвет у каждого клона свой (А — белый, Б — лаймовый), плашка у того, кто говорит.

## Шаги
1. Синхрон и дубли по **edit-talking-cut**, но дубли по ролям: `roles.json` — реплика → роль → дубль → время.
2. Звук: голос того, кто говорит; у молчащего клона звук дубля выключен (иначе шорох и дыхание двоятся).
3. Совмещение дублей: проверить сдвиг камеры по чистой плите (фазовая корреляция по краю мебели); если сдвиг > 1 px — выровнять `crop`/`translate` до композита.
4. Свет: средняя яркость кожи у клонов не расходится больше чем на 3 % — иначе кривыми.
5. HTML: плита → дубль А → дубль Б × маска (или шов) → субтитры ролей.

## Раскадровка-шаблон
1. Автор говорит тезис, справа пусто.
2. Справа появляется скептик-клон: «Звучит как фантастика».
3. Оба в кадре, реплики по очереди, цветные субтитры.

## Проверка
- Мебель на шве не «прыгает».
- Клоны не касаются друг друга в кадрах сплита.
- Липсинк каждого клона со своим звуком.

## Грабли
- Тени: клон Б отбрасывает тень на стену, которой нет у дубля А, — брать шов шире или маску с тенью вручную.
- Если штатив сдвинули между дублями, сплит не спасти — только перекрытие по маске с выравниванием.
